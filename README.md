# Base AI Chat

AI chat application powered by OpenAI API with Base wallet integration and AI agent capabilities.

---

## ✨ Features

- AI chat powered by OpenAI
- Base ecosystem assistant
- Wallet connection (Base / Coinbase Wallet)
- Wallet-based authentication (sign-in with wallet)
- AI-assisted on-chain interaction flow (user-approved)

---

## 🧠 Key Capabilities

- Conversational AI interface
- Wallet connect directly from chat UI
- Secure interaction flow via wallet approval
- Base ecosystem context-aware responses

---

## 🏗 Architecture Overview

User  
↓  
AI Chat (OpenAI API)  
↓  
Wallet Connect (Base / Coinbase Wallet)  
↓  
User Approval (Signature)  
↓  
Optional on-chain / agent action
